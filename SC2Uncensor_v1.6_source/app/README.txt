【这是什么】
  针对星际争霸2国服的反和谐工具。可以让大部分和谐特效恢复。
  国服客户端隐藏了"减少暴力表现"选项并强制和谐。
  本工具将此选项暴露，用户可手动切换 也可一键靠ocr自动点击切换, 以此恢复国际服的完整死亡特效。
  纯内存读写, 不修改任何游戏文件, 不联网, 源码全部公开。
  仅支持国服 Windows 64 位 V5.0.15/V5.0.16 版游戏: 内存偏移按这些版本写死, 
  启动时自动核对游戏版本, 版本不符会拒绝内存操作(防止写坏)，但是也有办法解除核对，详见常见问题Q3。
  (实测验证: 5.0.15.32043/5.0.16.97579)
  本工具依赖 Windows API(内存读写/全局快捷键), 只能在 Windows 上运行;
  macOS 版国服客户端目前不存在, 未来即便推出, Windows 源码也无法直接用——
  源码全部公开, macOS 用户可以参照本仓库思路让 AI 做一版适配。
  反和谐在首次切换成功后持续有效(即使关闭本工具), 直到退出游戏;
  重新启动游戏后需重新执行一次。
  ※ 注: 少部分战役场景模型跟随简中语音包依然和谐, 这目前不在本工具的作用范围内。

【快速上手】
  1. 启动星际2, 进入主界面(登录后)
  2. 双击 SC2Uncensor.exe 打开工具(拿到的是源码版? 见文末【关于启动方式】)。
     若 SC2 是以管理员启动的, 工具也要用管理员: 在"设置"里勾上"管理员启动"
     (或 config.json 设 "admin": true) 再重启工具; 也可以直接用设置里的"管理员重启"。
  3. 在工具界面上点"自动模式反和谐"(约2秒自动开菜单/选项/画面页并点击切换, 期间请勿同时操作,结束自动回到原界面), 或按 F9 同效。
     也可以点"手动模式反和谐"(或按 F8): 内存部分完成后, 自己去选项>画面设置 把"减少暴力表现"勾选→取消勾选 各一次。
  4. 进对局即可看到效果; 快捷键总开关：暂停后其他快捷键不再占用按键，也不干扰其他软件。
  ※ 界面上的按钮与下面的快捷键完全等价, 用哪个都行。
  ※ 界面里有"快速上手"一块常驻说明; 窗口最下面三个按钮是 使用说明 / 免责声明 / 杀软白名单, 随时可点。
  ※ 首次运行会弹免责声明(必须同意才能用); 每次工具更新后也会再弹一次。
  ※ 工具目录里会生成 sc2_uncensor.log(完整日志)与 ui_state.json(窗口位置等);
    界面上的"日志 / 关于"页签里能实时看日志, 也能一键打开这个文件。

【快捷键】(界面上的按钮与快捷键完全等价; 可在 config.json 自定义, 支持组合键与鼠标侧键)
  F8          = 手动模式反和谐(内存部分完成, 之后自己去选项里点一次)
  F9          = 自动模式反和谐(约2秒全自动, 无需手动操作)
  F11         = 自动切换和谐状态(再按一次切回)
  Ctrl+Alt+3  = 手动关闭反和谐修改(恢复内存, 再手动点一下选项)
  Ctrl+Alt+4  = 自动关闭反和谐修改(恢复内存+自动操作, 回到游戏初始态)
  Ctrl+Alt+2  = 显示当前状态(NOP / 存储位 / R, 纯查看)
  Ctrl+Alt+1  = 快捷键总开关(按一下暂停其他所有快捷键, 再按一下恢复;
                界面上这个按钮本身有小灯: 绿色=启用中, 灰色=已暂停)
  ※ 默认键选 F8/F9/F11 是因为 F1~F12 已全被星际2自带功能占用(闲兵/部队/镜头/成就/菜单/聊天/帮助等), 这几个在主界面恰好没有功能; 
    可用键名的完整列表见config.json 的 _说明。
  ※ 这些快捷键都是全局的: 工具运行期间会拦截相应按键(其他软件用不到)。
    默认开启"按键转发"(config.forward_keys): 触发快捷键时自动把按键异步转发给游戏, 对局内 F8(镜头)/F9(成就)/F11(聊天) 功能照常。
  ※ 对局内"减少暴力表现"选项锁定、无法操作: 检测到在对局内时自动点击会跳过(内存操作照常生效, 实测无害), 相关操作请回主界面。
  ※ 界面版里改快捷键是立即生效的(在"快捷键设置"里改); 直接编辑 config.json的则需要重启工具(界面版可以在"设置"里关掉再开)。

【常见问题】
  Q1: PVP等场景能使用吗？
  A1: 没有测试过，官方对PVE场景的管理非常宽松，但是PVP会严格一些，
     目前并没有在PVP场景下测试过，请谨慎对待。
  Q2: 杀毒软件报毒/删除了文件?
  A2: 内存读写工具的通病(误报)。请将本工具目录加入杀软白名单/信任区
     (360: 木马查杀→信任区; Defender: 病毒和威胁防护设置→排除项)。
     本工具不联网, 源码全部公开可自行审查。
  Q3: 游戏更新后失效?
  A3: 大版本更新会导致内部地址变化。工具启动时会自动核对游戏版本
     (实测支持 V5.0.15/V5.0.16 64位), 版本不符会明确提示并停止内存操作,
     不会写坏游戏——请到发布页获取适配版本。
     星际2已进入维护期, 小补丁的内存偏移通常不变: 版本核对拦住时可在
     config.json 设 "check_version": false 跳过核对自行尝试(风险自负);
     也可以自己给新版本加偏移条目, 方法见下面【进阶: 游戏更新后自己适配偏移】。
  Q4: 按快捷键没反应?
  A4: 先看日志里有没有"[按键] xxx"这一行 —— 界面版在"日志 / 关于"页签里,
     也可以直接打开工具目录下的 sc2_uncensor.log。
     · 没有 → 工具的按键处理卡住了(最常见原因见下一条"日志不滚动");
     · 有 → 再看它后面打印的流程日志, 会写明失败原因。
     另外看日志里有没有 "被占用" / "备用键" / "注册失败" 这些字样:
     旧工具窗口没关、或键位被其他软件占用时, 会自动换成备用键
     (日志打 "[提示] 快捷键 F8 被占用, xxx 已自动改用备用键 Ctrl+Alt+F8";
      界面版在"快捷键设置"里能看到实际生效的键位, 控制台版窗口里也有提示)。
     连备用键也全部失败会打 "[错误] 以下快捷键连同备用键全部注册失败: ..."。
  Q5: 日志不滚动了 / 快捷键像没反应?
  A5: 只会发生在控制台版(sc2_uncensor.bat, 源码运行): Windows 控制台的老毛病,
     在窗口里用鼠标划选文字时系统会暂停把输出交给程序(标记模式)。本工具已把输出
     改成后台线程异步写——即便窗口被划选, 工具运行和文件日志都不受影响(不会再有
     "按键全无反应"); 窗口显示会在你按 Esc 取消划选后继续, 滚轮查看历史日志不受影响。
     图形界面版没有控制台窗口, 不存在这个问题, 日志面板实时更新。
     要看/复制完整日志请直接打开 sc2_uncensor.log(记事本即可, 始终完整;
     源码运行时该文件在工具目录(源码包解开的目录)下, 程序版在 exe 同目录)。
  Q6: 自动模式反和谐定位失败?
  A6: ① 优先确认游戏不是"独占全屏": 自动模式要把游戏切到前台, 而独占全屏下
     Windows 常不允许别的程序抢前台(游戏会被挤到桌面)。若遇到, 请在游戏里把显示模式
     改成"无边框窗口"(看起来和全屏一样) —— 这是这类工具(含绝区零一条龙)的通行做法。
     工具遇到这种情况会明确提示, 而且不会乱点。
     ② 若日志里出现"桌面截图疑似全黑", 说明这个模式截不到画面: 把 config.json 的
     "screenshot" 改成 "printwindow" 再试(与绝区零一条龙同款截图 API)。
     ③ 或改用 F8 手动模式: 它不需要切前台, 全屏下也能用。
     ④ 若提示"勾选框蒙灰(对局内锁定?)"但明明在主界面: 多是那一刻截图抓到了黑帧
       (换显示模式/系统弹窗的瞬间两种截图方式都可能全黑), 再按一次即可; 反复出现
       就把 config.json 的 "screenshot" 改成 "printwindow" 再试。

【进阶: 游戏更新后自己适配偏移】(可选, 不感兴趣可跳过)
  工具的内存偏移按游戏版本写死在 offsets.dat 里(键 = exe 内部版本号)。游戏更新后
  版本核对会拦住, 三条路, 从省事到麻烦:

  ① 先试跳过核对: config.json 设 "check_version": false, 直接用。维护期小补丁的
     偏移通常不变, 多数情况这样就能用(风险自负: 核对被关掉后不会再有保护)。
  ② 给新版本加条目(推荐, 加完可整份 offsets.dat 分享给别人):
     1) 启动工具, 看日志里的版本号——"检测到游戏版本 X" 或 "[连接] ... 版本=X"。
        (也可以在资源管理器里右键 SC2_x64.exe → 属性 → 详细信息 → 文件版本 查看。)
        注意 offsets.dat 的键要用这个 exe 内部版本号 X, 不是战网显示的版本号!
     2) 打开 offsets.dat(内容就是 JSON, 后缀刻意用 .dat 防误改), 把现有条目整段
        复制一份, 键改成 X, "display" 改成战网显示的版本号(仅用于显示)。
     3) 保存后重启工具, 若日志出现"已从 offsets.dat 载入 X 的偏移"说明条目被采用;
        再按 F11 试一次: 能正常切换(存储位跟着翻转、画面同步变化) = 偏移没变, 收工。
        日志里没有"已载入"那行 = 条目格式写错了(JSON 语法/十六进制), 检查后重来。
  ③ 偏移真的变了, 需要重新定位(要有动手能力, 建议交给 AI 做):
     · store(存储位)与 r: 用"状态差分"——挂载游戏后把整个模块快照存档, 在游戏里
       正常勾选/取消一次"减少暴力表现", 期间连续快照做差分; 只有勾选状态翻转时
       跟着翻转的那 1 个字节就是新的 store(0=未勾选 / 1=勾选); r 同理, 在完整/和谐
       切换时看谁在 0↔1 之间变(0=和谐 1=完整 2=国服强制)。
     · nop_sites 三处: 取旧偏移前后 32 字节当特征, 在新版 exe 里搜同样字节
       (维护期补丁的指令排布通常不变); 命中后核对周围指令语义一致再填。
       每处的"原始字节"必须照抄真实值——关闭反和谐功能时要写回它。
     文件格式: nop_sites 每项 = [偏移, 原始字节(2字节的十六进制文本)]; 偏移是
     "模块内偏移" = Ghidra 里看到的地址减 0x140000000; store/r 是十六进制字符串。
  仓库里 docs/偏移维护指南.md 有更详细的流程和排错(该文件不随工具打包, 需要时到
  开源仓库看)。

【关于启动方式(程序版 / 源码版)】
  本工具分两种包, 界面与功能完全一样:
  · 程序版(推荐): 解压后双击 SC2Uncensor.exe 即用, 不需要 Python、不需要任何 bat。
  · 源码版: 给杀软敏感、或想自己审查/修改源码的用户(内容与 GitHub/Gitee 仓库一致)。
      1) 安装 64 位 Python 3.8+(安装时勾选 "Add Python to PATH");
      2) 在源码目录里执行(两条命令, 装一次就行):
           python -m venv .venv
           .venv\Scripts\pip install pymem psutil pillow winocr
      3) 双击 sc2_uncensor_ui.bat(图形界面版)或 sc2_uncensor.bat(控制台版,
