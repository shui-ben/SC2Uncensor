启动方式与启动器说明（源码版用户与仓库开发者看；exe 程序包用不到本文件）
======================================================================

一句话：拿到发布包（SC2Uncensor.exe）的人**不需要任何 bat**——那个 exe 里已经带了
Python 运行时。本文件讲的是**在源码仓库里怎么跑**，以及仓库里那些 bat 各自是干什么的。

----------------------------------------------------------------------
一、发布包 vs 源码仓库（先分清，很多描述只对其中一边成立）
----------------------------------------------------------------------
  发布包（dist\SC2Uncensor\，发给别人用）
    双击 SC2Uncensor.exe 即可，不需要装 Python、不需要 bat。
    数据文件（config.json / offsets.dat / README.txt / win_ocr_json.ps1）就在 exe 旁边，
    用户直接改得到；日志 sc2_uncensor.log 与状态 ui_state.json 也生成在这里。

  源码仓库（本目录的上级，开发/调试用）
    走 .venv 里的 Python，由 app\ 下这两个 bat 启动；必须先有 .venv（项目根目录）。
    **这两个 bat 不随发布包分发**：它们写死了 `.venv\Scripts\python.exe`，拷到没装
    环境的机器上只会报错，所以干脆不打包（打包脚本的 DATA_FILES 里没有它们）。

----------------------------------------------------------------------
二、app\ 下的两个启动器
----------------------------------------------------------------------
  app\sc2_uncensor.bat      控制台版（python.exe）
    · 双击后开一个控制台窗口，工具的全部日志实时打在里面，适合排查问题。
    · 提权：读 config.json 的 "admin"；为 true 且当前不是管理员时，弹 UAC 重启自己
      （判断逻辑独立成 app\admin_flag.py，免得 bat 里出现括号/嵌套引号这种高危写法）。
    · ASCII-only + CRLF 是刻意的：bat 不能依赖控制台代码页（曾因 chcp 65001 + UTF-8
      中文行导致 cmd 解析错位、"双击一闪而过"）。
    · 等价的手工命令（在项目根目录执行）：
        .venv\Scripts\python.exe app\sc2_uncensor.py

  app\sc2_uncensor_ui.bat   图形界面版（pythonw.exe，无控制台窗口）
    · 双击后只出现界面窗口，没有控制台。提权由界面自己做（启动时读 config.json 的
      "admin"；界面里的"设置 → 管理员重启"也能随时提权重启）。
    · 手工等价命令：
        .venv\Scripts\pythonw.exe app\ui_main.py

  另外：scripts\build_exe.py 是把产品打成发布包的地方，根目录的 build_exe.bat /
  build_exe_notest.bat 就是它的双击入口（详见 docs\打包说明.md）。

----------------------------------------------------------------------
四、写/改 bat 时的三条硬规矩（这个项目踩过的坑，别踩第二遍）
----------------------------------------------------------------------
  1. **ASCII-only + CRLF**：中文行在 936 代码页下会让 cmd 解析错位，表现为"双击闪退"。
     要提示中文就交给 Python 打印（py 里的 stdout 已做编码兜底）。
  2. **不要用 `if ( ... )` 括号块**：块内 echo 只要带一个 `)`（哪怕看起来是配对的），
     cmd 就会认为块提前结束 → 报"此时不应有 ."然后窗口一闪而过。用 `<label>` + `goto`。
  3. **判断提权这种逻辑放 py 文件**（如 admin_flag.py），bat 里只留 `for /f` 取结果，
     避免在 bat 里拼括号/嵌套引号。
