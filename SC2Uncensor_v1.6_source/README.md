# 星际争霸2 国服反和谐工具（视觉还原）· 源码包

本目录是 **v1.6 稳定版** 的源码包：`app\` 里是全部产品源码与数据文件，
和程序包 `SC2Uncensor_v1.6_win64.zip` 里的 exe **完全同源**。
想省事请直接用程序包（解压双击 `SC2Uncensor.exe`，不需要 Python）；
这个包给杀软敏感、或想自己审查/修改源码的人。

> 注：这是源码包自带的说明，与开发仓库（私有）里那份面向开发者的 README.md 不是同一份。

国服客户端把"减少暴力表现"选项藏了起来、并强制和谐。本工具把那个选项找回来，
并自动切换它，恢复国际服的完整死亡特效表现。
**纯内存读写**（ReadProcessMemory / WriteProcessMemory）：不修改游戏任何文件、
不联网、无遥测。会话级生效（游戏重启后需要再执行一次）。

## 一、运行（源码版）

1. 安装 64 位 Python 3.8+（安装时勾选 "Add Python to PATH"）；
2. 在本目录执行（两条命令，装一次就行）：
   ```bat
   python -m venv .venv
   .venv\Scripts\pip install pymem psutil pillow winocr
   ```
3. 双击 `sc2_uncensor_ui.bat`（图形界面版）或 `sc2_uncensor.bat`（控制台版，
   日志实时打在窗口里，排查问题用）。

## 二、快速使用

1. 启动星际2，进入主界面（登录后）；
2. 在工具上点 **"自动模式反和谐"**（或按 `F9`）：约 2 秒自动完成
   "内存部分 + 打开 选项>画面 + 点击切换 + 返回原界面"；
   也可点 **"手动模式反和谐"**（`F8`）：只做内存部分，然后自己去
   选项>画面设置 把"减少暴力表现" 勾选 → 取消勾选 各一次；
3. 进对局即可看到效果；`F11` 可随时在 和谐/反和谐 之间切换。

| 快捷键 | 功能 |
|---|---|
| `F8` | 手动模式反和谐（内存部分，之后自己去选项里点一次） |
| `F9` | 自动模式反和谐（约 2 秒，全程无需操作） |
| `F11` | 自动切换和谐状态 |
| `Ctrl+Alt+1` | 快捷键总开关（暂停/恢复其他所有快捷键） |
| `Ctrl+Alt+2` | 显示当前状态 |
| `Ctrl+Alt+3` | 关闭反和谐·手动（恢复内存，再手动点一下选项） |
| `Ctrl+Alt+4` | 关闭反和谐·自动（恢复内存 + 自动操作，回到游戏初始态） |

界面上的按钮与快捷键完全等价；快捷键可在界面"快捷键设置"里改（立即生效）。

## 三、支持范围与使用边界

- **仅国服 Windows 64 位客户端 V5.0.15 / V5.0.16**（实测 `5.0.15.32043`）。
  启动时自动核对游戏版本，不符则拒绝内存操作（防写坏）；被拦时可在 `config.json`
  设 `"check_version": false` 自行尝试（风险自负），或按 `docs/偏移维护指南.md` 适配。
- **PvE（合作/战役/自定义AI）**：官方管理宽松，作者长期在 PvE 使用
  （最初测试用小号，现在已用大号正常游玩），没出过问题。
- **PvP（天梯/对战）**：没有测试过，且PVP管理更严，所以说不建议，要试请自行谨慎测试。
- **仅 Windows**；修改客户端违反暴雪 EULA，使用风险自负，本工具与暴雪娱乐无关；
  完全免费，请勿转卖或改名冒充。

## 四、自己重新打包（可选）
